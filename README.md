## v1.2.2
- Rebuilt Highlight editor to match the CrownBoard UI.
- Existing Highlight screenshot is shown while editing and remains unless explicitly changed.
- Replaced browser-style Highlight file input with a Change Photo action.
- Replaced prompt-based Data History editing with an in-app CrownBoard stats editor.
- Historical seasons and snapshots can edit Matches, Wins, Top 10, Top 25, and Eliminations in one sheet.
- Calculated Win Rate, Top 10 %, Top 25 %, E/G, K/D, and Crown Score update live while editing.
- Removed unnecessary "Editable" wording from Data History.
- Data History cards now show all entered raw Fortnite stats plus calculated performance rates.
- Renamed Season-over-Season to Stat Comparison.
- Stat Comparison lets you choose any two completed/current seasons or Career.
- Stat Comparison includes raw totals, rates, E/G, K/D, and Crown Score.
- All user-facing season names now use compact CxSx formatting (for example C7S2).
- Raw Top 10 / Top 25 cards use a cleaner count + percentage layout.
- Existing crownboard-v1 data key is retained.
- Service-worker cache bumped to crownboard-v1-2-2.
